# Interfaces Cérebro-Máquina: transformando a vida de pessoas com deficiências físicas

Projeto de pesquisa do Trabalho Interdisciplinar III: Pesquisa Aplicada (2025/1), do Bacharelado em Ciência da Computação da PUC Minas (ICEI). O artigo propõe investigar uma interface cérebro-máquina (ICM/BCI) não invasiva para apoiar pessoas com deficiências físicas. A metodologia descreve o uso de sinais de eletroencefalografia (EEG), imaginação motora e classificação de sinais como etapas planejadas. Este repositório reúne o artigo e materiais de apresentação.

**Autoras:** Bruna Furtado da Fonseca e Marcella Santos Belchior.

**Orientador:** João Pedro Oliveira Batisteli.
