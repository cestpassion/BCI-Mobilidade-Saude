# Projeto de pesquisa

Esta pasta reúne o artigo **“Interfaces Cérebro-Máquina: transformando a vida de pessoas com deficiências físicas”**, de Bruna Furtado da Fonseca e Marcella Santos Belchior, e o arquivo ZIP com suas fontes LaTeX.

- [Artigo em PDF](Artigo_BCI-Mobilidade-Saude.pdf) — texto de 11 páginas com introdução, referencial, trabalhos relacionados, metodologia, resultados esperados e conclusão.
- [Fontes LaTeX em ZIP](Artigo_TI3.zip) — arquivos do projeto do artigo.

A metodologia propõe uma ICM não invasiva baseada em EEG e imaginação motora, com classificação de sinais planejada.
